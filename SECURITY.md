# Security policy

## Reporting a vulnerability

Report it privately, through GitHub's
[security advisory form](https://github.com/mmedum/gitlab-mcp/security/advisories/new)
on this repository. Do not open a public issue.

Include what you did, what happened, what you expected, and the version
(`gitlab-mcp --version`, a release tag or a commit). Describe the shape
of the problem; never include a token, an application id, or anything
from your instance.

## Supported version

Only the latest release receives fixes. A fix ships as a release of its
own.

## Response

We acknowledge a report within **7 days**.

[`docs/security.md`](docs/security.md) is the threat model. It says what
counts as a vulnerability here and what does not.
