passed on that commit. Release run `39788192059` passed: `verify-ci`,

commit, under Go 1.27.3. `ci` passed on the pull request and on `main`.

dependencies in a Free group, and a full run with a client that could
be asked, in which no question was put.

## Found during the release

- **Before the cut:** the security review over `v2.4.0..HEAD` found no
  finding at confidence 8 or above and one low one, recorded in §16a:
  `apply_suggestions`' witness covers the text a suggestion puts in,
  not the lines it replaces (`audit/security-reviews/v3.0.0.md`). The
  history scan flagged Dependabot's sign-off address on the bumps
  merged since 2.4.0; it is now allowed by name, with its reason.
- **During the release:** `govulncheck` in CI on the release pull
  request found GO-2026-6809 in `crypto/x509`, published after the
  local run that found nothing. The release moved to Go 1.27.3, which
  fixes it, with a Security line in the CHANGELOG. Two Dependabot pull
  requests, the CodeQL and goreleaser actions, were merged before the
  tag.
