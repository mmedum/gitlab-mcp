# Release verification — v4.0.0

Tagged `fcdc111` on 2026-10-23, the merge of pull request 68, after `ci`
passed on that commit. Release run `39964729782` passed: `verify-ci`,
`goreleaser` and `registry / publish`, and its log was read.

## Gates

`make check` passed on the release branch and on `main` at the tagged
commit, under Go 1.27.3. `ci` passed on pull requests 67 and 68 and on
`main`. Before the cut, `make deps`, `make schema-refetch`,
`make leaks-history` and `make schema-diff` passed; the schema diff read
two tools added and three changed in description and `_meta` only
against v3.0.0, all in the CHANGELOG. `govulncheck` found nothing at
v3.0.0 or at the release. `make release-rehearse` built every archive,
the bundle in `checksums.txt`. A live run on gitlab.com drove both new
tools, and its transcript was read: `rerequest_review`'s GraphQL
mutation moved the run's account from reviewed to unreviewed, and
`make_issue_public` made an issue public after `update_issue` refused
to with every flag on.
