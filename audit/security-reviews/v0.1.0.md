# Security review — v0.1.0 (phase 0)

Range: the design commit `c724309` to the phase 0 build `a4d95fd`, run
with `/security-review` on 2026-09-26 before the review fixes and the
simplification pass. Scope: the code that ships (`cmd/gitlab-mcp`,
`internal/**`) and the workflows.

**Result: no HIGH or MEDIUM finding at confidence 8 or above.**

What was examined, and why each path holds:

- **The token reaches only the configured instance.** It is attached
  only after a same-origin check; no redirect is followed by any HTTP
  client; a moved project is re-requested once, as a GET, only under
  the API root.
- **Pagination.** `Link: rel="next"` is honored only under the API root
  with the same decoded path; page tokens carry pagination keys only,
  never a URL, bound by hash to the request.
- **Model arguments in URLs.** Paths come from literal templates;
  every segment is escaped once; empty, control-character and dot
  segments are refused. The model controls at most a path on the
  configured host.
- **OAuth loopback.** `127.0.0.1` on a random port; `state` and the
  PKCE verifier from `crypto/rand`; S256; no secret and no `resource`
  parameter sent; callback errors written as plain text.
- **Token withholding.** A configured instance that differs from the
  profile's gets no token and no refresh; `logout` revokes at the
  instance the profile records.
- **TLS.** A CA file is added to the system pool; verification is never
  skipped; plain http is refused off loopback unless explicitly allowed.
- **Files.** Profile names are validated by pattern; the config-dir
  override is confined to the home directory by real path; files are
  written 0600 through a temporary file and a rename.
- **Logs and errors.** Transport errors are stripped of URLs and
  addresses; token-body errors are replaced by fixed text; settings
  redact the client id; tool logs carry name, outcome, duration and
  bucket only.
- **Untrusted content.** A per-call boundary token from `crypto/rand`;
  forged markers defused; origin fields stripped of control characters.
- **Workflows.** CI runs on `pull_request` with `contents: read`; no
  path from untrusted input was found.

The code review of the same range found two items with a security
edge — an outside link that could read as on the instance, and a
hostname reaching logs through a nested DNS or TLS error — both fixed
in `637c982` and recorded in `docs/architecture.md` §16a.
